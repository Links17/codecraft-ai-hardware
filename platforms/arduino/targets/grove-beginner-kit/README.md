Device knowledge: [hardware.md](../../../../devices/grove-beginner-kit/reference/hardware.md). Read the [toolchain setup](../../../../devices/grove-beginner-kit/reference/toolchain.md), then run `python3 codecraft.py validate --target arduino/grove-beginner-kit --projects` from the repository root.
