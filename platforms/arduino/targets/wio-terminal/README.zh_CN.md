# arduino/wio-terminal

硬件知识：[hardware.md](../../../../devices/wio-terminal/reference/hardware.md)。阅读[工具链安装说明](../../../../devices/wio-terminal/reference/toolchain.md)，然后在仓库根目录运行 `python3 codecraft.py validate --target arduino/wio-terminal --projects`。

Target 清单定义 FQBN、依赖版本和独立示例。使用 --example 选择一个示例。构建不会上传；实机步骤由 [Device 验收清单](../../../../devices/wio-terminal/tests/hardware-checklist.md)维护。
