# On-device acceptance

No physical pass is inferred from source organization or compilation. Each devices/<device>/AGENTS.md embeds the acceptance contract and renders the minimum workflow. Exercise each claimed example, shared buses and restart/recovery on the actual board revision. Keep sanitized evidence and logs under tests/devices/<device>/ as specified in [tests/AGENTS.md](../tests/AGENTS.md); use record-evidence to validate and register them. Display changes need visual observations, audio changes need observed sound/capture, and power changes need measured results.
